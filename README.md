# Krishi Sahaya – AI-Powered Agricultural Decision Support System

Krishi Sahaya is an end-to-end AI-driven platform designed to assist farmers with yield risk prediction, irrigation decisions, and context-aware agricultural recommendations. It integrates Machine Learning, Retrieval-Augmented Generation (RAG), and MLOps pipelines into a unified system.

---

## Overview

The system combines predictive modeling with knowledge retrieval and large language models to provide actionable insights to farmers. It is built with a modular architecture enabling scalability, monitoring, and continuous improvement.

---

## Features

- Yield risk prediction using a Random Forest model  
- Context-aware agricultural recommendations  
- Retrieval-Augmented Generation (RAG) using ICAR documents  
- Conversational chatbot interface powered by LLM  
- Automated MLOps pipeline with training and drift detection  
- Monitoring using Prometheus and Grafana
